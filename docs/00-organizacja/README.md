# Organizacja kursu

## Cel kursu

Kurs wprowadza początkującego ucznia w podstawy programowania w języku Python. Materiały są ułożone od najprostszych tematów do pierwszych samodzielnych projektów.

Uczeń uczy się pisać proste programy, uruchamiać kod, poprawiać błędy i korzystać z podstawowych konstrukcji języka Python.

## Jak korzystać z kursu

Lekcje najlepiej realizować po kolei, ponieważ kolejne tematy korzystają z wcześniejszych wiadomości.

- Przepisuj przykłady samodzielnie.
- Uruchamiaj kod po każdej istotnej zmianie.
- Analizuj wyniki działania programu.
- Czytaj komunikaty błędów spokojnie i krok po kroku.
- Wykonuj ćwiczenia znajdujące się w lekcjach.
- Wracaj do wcześniejszych materiałów, gdy czegoś nie pamiętasz.
- Regularnie zapisuj swoją pracę.
