# Algorytmy - klasa III

W klasie III skupiamy się na klasycznych algorytmach matematycznych i maturalnych. W tym dziale przetwarzamy również cyfry liczb i napisów oraz wykonujemy konwersje systemów liczbowych.

Najważniejsze jest rozumienie metody, a nie samo zapamiętanie kodu. Kod w Pythonie służy do sprawdzenia pomysłu i przećwiczenia implementacji.

Do lekcji o cyfrach i konwersjach potrzebujesz pętli, podstaw napisów i [podstaw list](../../08-listy/README.md).
