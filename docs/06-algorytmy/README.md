# 06. Algorytmy

Algorytm to uporządkowany sposób rozwiązania problemu. Można go porównać do przepisu: najpierw wykonujemy pierwszy krok, potem drugi, potem następny.

Jeden problem może mieć kilka poprawnych algorytmów. Niektóre są krótsze, inne łatwiejsze do zrozumienia, a jeszcze inne szybsze dla komputera.

Algorytm można opisać na kilka sposobów:

- słownie,
- za pomocą schematu blokowego,
- za pomocą kodu programu.

W tym dziale najpierw uczymy się rozumieć sposób rozwiązania. Dopiero później oglądamy implementację w Pythonie.

## Dlaczego kod jest ukryty?

Kompletne rozwiązania w Pythonie są domyślnie ukryte. Chodzi o to, żeby najpierw pomyśleć:

- jakie dane mamy na wejściu,
- jaki wynik chcemy otrzymać,
- jakie kroki prowadzą do wyniku,
- dlaczego te kroki działają.

Kod można rozwinąć dopiero wtedy, gdy rozumiesz pomysł na algorytm albo chcesz sprawdzić swoje rozwiązanie.

## Jak pracować z algorytmem?

1. Przeczytaj opis problemu po ludzku.
2. Zrozum prostą analogię.
3. Sprawdź dane wejściowe i wynik.
4. Przejdź kroki algorytmu ręcznie.
5. Spróbuj wyjaśnić algorytm własnymi słowami.
6. Dopiero potem rozwiń implementację w Pythonie.
