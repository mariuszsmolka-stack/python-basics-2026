# Algorytmy - klasa I

W klasie I skupiamy się na prostych algorytmach, które można zrozumieć bez zaawansowanych struktur danych.

Najważniejsze są:

- czytanie treści zadania,
- wybór potrzebnych danych,
- sprawdzanie warunków,
- wyjaśnianie działania programu własnymi słowami.
