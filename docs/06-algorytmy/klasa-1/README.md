# Algorytmy - klasa I

W klasie I skupiamy się na prostych algorytmach, które można zrozumieć bez zaawansowanych struktur danych.

Po warunku istnienia trójkąta poznajemy cztery algorytmy: wyodrębnianie cyfr z liczby, zamianę znaków napisu na cyfry, zapis liczby w systemie dwójkowym i odczyt zapisu dwójkowego. Następnie uogólniamy konwersje na inne podstawy.

Do nowych lekcji potrzebujesz pętli, podstaw napisów i [podstaw list](../../08-listy/README.md). Kod jest ukryty, aby najpierw prześledzić obliczenia ręcznie.

Najważniejsze są:

- czytanie treści zadania,
- wybór potrzebnych danych,
- sprawdzanie warunków,
- wyjaśnianie działania programu własnymi słowami.
