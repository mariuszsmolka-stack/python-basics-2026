# Python - podstawy programowania 2026/2027

Repozytorium zawiera materiały do kursu podstaw programowania w języku Python.

Kurs jest przeznaczony dla uczniów klasy I liceum oraz osób początkujących. Materiały spokojnie wprowadzają w podstawy programowania: od pierwszego programu, przez zmienne i warunki, aż do prostych pętli oraz projektów. Na zajęciach pracujemy głównie w JupyterLab.

## Zakres

- pierwszy program w Pythonie,
- funkcja `print()`,
- zmienne,
- podstawowe typy danych,
- komentarze,
- operatory,
- funkcja `input()`,
- konwersja typów,
- bloki kodu i wcięcia,
- `if`, `if-else` i `elif`,
- `match-case`,
- pętla `while`,
- licznik i akumulator,
- pętla `for` i funkcja `range()`,
- `break` i `continue`,
- obecne trzy projekty.

## Materiały

Strona startowa kursu znajduje się w pliku [docs/index.md](docs/index.md). Pełny spis lekcji jest dostępny w nawigacji kursu. Lekcje najlepiej realizować w przedstawionej tam kolejności.

## Zasady

Przykłady w kursie są proste i przeznaczone dla osób początkujących. Warto samodzielnie przepisywać programy, uruchamiać je po zmianach i wykonywać ćwiczenia znajdujące się w lekcjach.
